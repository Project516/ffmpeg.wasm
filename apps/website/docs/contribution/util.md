# @project516/ffmpeg-wasm-util

The source code of @project516/ffmpeg-wasm-util locates at **/packages/util**.

## Development

```bash
$ pnpm run dev
```

## Build

Transpile Typescript to JavaScript.

```bash
$ pnpm run build
```

## Lint

```bash
$ pnpm run lint
```

## Publish

Simply run `pnpm publish` under **packages/util**.
