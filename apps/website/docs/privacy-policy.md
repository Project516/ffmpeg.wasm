# Privacy policy

Last updated: September 24, 2026

This site is a static Docusaurus site hosted on GitHub Pages. It does not run
any analytics or advertising, and it does not set cookies of its own.

## The playground

The playground on this site runs FFmpeg inside your browser using
WebAssembly. Files you open in the playground are processed on your device
and are never uploaded anywhere.

The FFmpeg core (`ffmpeg-core.js` and `ffmpeg-core.wasm`) is loaded from the
[jsDelivr](https://www.jsdelivr.com/) CDN. jsDelivr sees the request for that
file, the same way any CDN does, since your browser fetches it directly. See
jsDelivr's own [privacy policy](https://www.jsdelivr.com/terms/privacy-policy)
for what they log.

## Search

Search on this site runs entirely in your browser, against a search index
generated when the site is built. No search query leaves your device.

## GitHub Pages

This site is hosted on GitHub Pages. GitHub may log requests to the site
(such as IP address and requested page) as part of running the service. See
[GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)
for details.

## Contact

Questions about this policy can be raised as a
[GitHub issue](https://github.com/Project516/ffmpeg.wasm/issues).
